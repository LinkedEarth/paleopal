# Utilities: CCM configuration

## Contents

1. [Expand Master Parameter List](1_setup__expand_master_param_list.ipynb)
2. [Configure CCM Run Sets](2_setup__configure_CCM_run_sets.ipynb)

Supporting notebooks that configure the parameter sweep — expanding the master list
of (E, τ, lag, dataset) combinations and organizing them into run sets. These aren't
one-time setup: they're rerun as the parameter sweep or dataset selection changes.
They don't produce narrative figures, but
[A Single CCM Calculation](../2_CCM_single_dyad/1_run__CCMlocally.ipynb) (which
does) depends on their output — see Part 3, earlier in the book.
