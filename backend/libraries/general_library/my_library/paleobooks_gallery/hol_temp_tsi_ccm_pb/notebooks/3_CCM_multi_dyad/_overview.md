Having established CCM skill for one dyad at a time (previous section), this section
pulls results together across dyads. `0_calc__final_result_grid` assembles the
combined result set. The main result grid (Fig. 3, pictured below) covers the four core
temperature–TSI dyads (Erb22 and GISP2/Alley00, each against Wu18 and Vieira11); the
fuller supplementary overview (Figs. S6, S7, S9) extends to six more dyads, adding
Tian22, Döring22, and both Seierstad14 and Martin24 δ¹⁸O/temperature series, mostly
against Wu18.
